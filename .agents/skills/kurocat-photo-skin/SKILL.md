# 制作 KuroCat 自定义猫咪皮肤

## 确定底稿

先确认每份参考用在哪里。用户说「参考上一只的画风」时，沿用像素颗粒、毛纹疏密、明暗色块和边缘处理。用户说「以这一版为基础」时，从指定皮肤 JSON 解出 `photo.png`，沿用已确认的表情和部件坐标。只简化毛纹时，保留眼鼻口像素、胸毛轮廓和大块明暗。用户单独指定部件形状或手部动作时，把参照范围限定在该部件或动作。

根据目标猫的正面和侧面照核对两眼底色、眼形、鼻梁白斑和脸罩边界。用不同光线下的照片交叉确认异瞳，单张照片中的高光或阴影不足以定色。用全身照确定颈毛宽度、胸前白毛垂到哪里、身侧深色覆盖范围和尾形。照片里戴着伊丽莎白圈时，分别辨认圈沿与真实颈毛，被挡住的毛色优先从其他角度核对。

原版手绘皮肤可通过 `pattern` 和 `portrait` 表达个体特征。像素画或实拍关节版先制作同一姿势的完整底稿，再拆出五个透明部件，补齐活动时会露出的区域。[字段、尺寸与示例](references/skin-format.md)

## 分层和衔接

- 头部带一小段颈毛，躯干上端在下巴后方留出重叠区。用相邻胸毛的颜色延伸被遮挡部分，让头部下沿的透明度沿毛流渐变。棋盘点阵、深色横边在头身相对移动时会闪动。
- 分开躯干、尾巴、上臂、带爪前臂。躯干保留后脚，移出承担敲键动作的两只前爪，避免抬爪后胸前又露出一对静止爪。按实际贴图测量五个矩形。眼睛的中心和半径相对于**头部矩形**，包含矩形内的透明留白。
- 从肩到爪尖记录上臂、前臂、爪尖三处毛色，以及分界沿腿长的位置。例如咪咪的上半段深、下半段白，白毛从腿中段延伸到爪尖。绘制时按目标猫照片确定白毛长度。需要伊丽莎白圈时另画透明的 `rig.collar`，让圈沿遮住肩根，并在低头时检查脸部是否露全。
- 先选动作再填材质。沿用原版爪形和敲键时序时，同时启用 `rig.originalPaws` 和 `rig.classicPawMotion`。要复现分段腿色时按[前腿取色规则](references/skin-format.md#原版前爪的双色毛发)准备贴图。需要自绘弯肘轮廓时，由 `upperLeg` 和 `foreleg` 两段贴图驱动。原版坐姿可启用 `rig.classicPose`，头身联动可启用 `rig.joinedNeck`。像素画需要平滑移动时同时设置 `photo.pixelArt` 和 `photo.smoothEdges`。

## 打包和试玩

从项目根目录运行。准备 UTF-8 的 `skin-meta.json`，填好名称、颜色、`photo.eyes` 和 `photo.rig`，另存一张透明的 `atlas.png`。打包脚本将 PNG 嵌入元数据并写出一个可分发的 JSON。纯参数版直接使用其 JSON。

```sh
node .agents/skills/kurocat-photo-skin/scripts/pack.mjs skin-meta.json atlas.png custom-cat.json
node .agents/skills/kurocat-photo-skin/scripts/preview.mjs custom-cat.json
```

预览使用项目已有的 Vite 依赖（首次可运行 `npm ci`），在终端打印的本机地址打开试玩区。点击内置皮肤可在同一画布上对照。桌面端右键桌宠，选择「导入猫咪皮肤…」。已导入的皮肤可以重复导入相同文件。修改过素材后，使用新的 ID，方便与原版并存。

## 动态验收

1. 将目标猫正面照与试玩待机帧并排，核对眼色、脸纹、颈毛大小、胸腹与四肢的颜色分布。再按相同显示尺寸与画风参考比较毛纹和边缘。观察呼吸、眨眼时嘴角是否稳定、眼皮是否覆盖双眼。
2. 左右爪分别敲键，连敲相邻键和跨区键，接着握鼠标、点击、松开回待机。在收爪、伸到最远和落键几帧检查爪尖落点、两段毛色是否沿腿转动、肩根有无穿过圈沿，以及抬爪后是否出现重复前爪。若有顿挫，分别测量帧间隔和相邻帧的爪尖位移。
3. 在打字低头、左右侧倾时放大颈部连续几帧，检查露底、点阵闪动、耳尖和脸颊的阶梯感。切换 65% 和 108 键布局并试一次密码闭眼。看接缝用连续画面，看表情用同姿态局部对照。
4. 交付自定义皮肤 JSON。用户要看动作时，提供实际试玩地址或引擎录屏。需要前后对照时，两边使用相同输入、布局、缩放和播放速度。
